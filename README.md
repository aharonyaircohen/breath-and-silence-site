# נשימה ושקט - האתר הציבורי

אתר קריאה בעברית המציג את המודל, הביסוס המחקרי, התהליך ותוכנית הניסוי.

כתובת האתר: https://aharonyaircohen.github.io/breath-and-silence-site/

## תפקיד המאגר

זהו מאגר פרסום ציבורי. מקור האמת של הקורס הוא הריפו הפרטי `aharonyaircohen/breath-and-silence`. מסמך המודל וסיכומי המקורות כאן הם תוצר פרסום נבחר; אין סנכרון אוטומטי או אישור לפרסום כל שינוי עתידי במאגר הפרטי.

- `content/model.md` - צילום פרסום של מסמך היסוד, ללא נתוני משתתפים.
- `content/research.json` - ספריית מקורות ציבורית מצומצמת: פרטים ביבליוגרפיים, סיכום, רלוונטיות ומגבלה.
- `scripts/build.py` - יצירת HTML סטטי מהתוכן המאושר.
- `assets/` - עיצוב RTL והתנהגות חיפוש בדפדפן.
- `docs/` - האתר המופק, שממנו GitHub Pages מגיש את הדפים.
- `tests/` - בדיקות השלכת מידע ציבורי, קריאה, escaping וקישורים.

## בנייה ובדיקה

דרושים Python 3 ו־Python Markdown בגרסה הרשומה ב־`requirements.txt`.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/build.py --base /breath-and-silence-site/
```

האתר סטטי: אין שרת יישום, הרשמה, איסוף תשובות לסקר או כלי אנליטיקה חיצוניים. החיפוש והסינון מתבצעים בדפדפן. GitHub עשויה לשמור יומני בקשות לפי מדיניותה.

## כללי תוכן

נשמרת הבחנה בין המודל, ממצאים, פרשנות והשערות. מקור במאגר אינו בהכרח ניסוי או ממצא חיובי. אין להוסיף הבטחות ריפוי, אבחנת התמכרות לכל אדם, הנחיות נשימה אינטנסיביות, או טענה שקוהרנטיות וגל מוחי הם מד־עומק אוניברסלי.

אין להוסיף לכאן ארכיון מאמרים מלאים, פסקאות מקור ארוכות, נתיבי מחשב, תכתובות, מפתחות או מידע אישי/רפואי של משתתפים. לפני כל פרסום יש לבדוק את התוכן המוקרן, הקישורים, החיפוש, המובייל והפריסה החיה.

כל הזכויות בתוכן המקורי שמורות לבעליו; זכויות במאמרים חיצוניים נשארות לבעלי הזכויות שלהם. הקישורים והסיכומים אינם רישיון להפצת המאמרים המלאים.
