מה מתועד במקור?

בניסוי אקראי, אימון מיינדפולנס שיפר זיכרון עבודה וביצועי הבנת הנקרא והפחית נדידת מחשבות. אצל מי שהיו מועדים להסחה, הירידה בנדידת המחשבות תיווכה סטטיסטית את השיפור בביצוע.
